# SlitLamp v1.12.1

데스크탑 앱(맥·윈도우) 설정 창의 카메라 고르기를 고쳤습니다.

- 목록 칸(소스 모드·카메라·사진 형식)에 ▼ 화살표가 보입니다. 어두운 화면에서 화살표가 안 보여 고를 수 없는 칸처럼 보이던 문제를 고쳤습니다.
- 카메라는 이름 목록에서 고릅니다. 카메라를 연결하거나 USB 스트리밍으로 바꾼 뒤 **다시 찾기** 를 누르면 목록이 새로 고쳐집니다.
- 저장한 카메라가 지금 보이지 않으면 설정 창에 주황색 안내가 나옵니다.
- 샘플 사진 가져오기(v1.12.0)와 AI 에이전트 에디션(v1.11.0)은 그대로입니다. 웹 버전은 v1.11.0 과 같습니다.

다운로드
- Windows: SlitLampImaging-Setup-1.12.1.exe (기본), KeelerSlitLamp-Setup-1.12.1.exe (Keeler), SlitLampAgent-Setup-1.12.1.exe (AI 에이전트).
- Mac: 기본/Keeler/에이전트 각각 arm64(Apple Silicon)·x86_64(Intel) DMG.
- 웹: SlitLamp-Web-1.12.1.zip. 전체 소스: SlitLamp-Source-1.12.1.zip. SHA256SUMS.txt 로 무결성을 확인할 수 있습니다.

기존 데이터는 그대로 사용합니다.
