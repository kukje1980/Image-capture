# SlitLamp v1.18.4

멀티 화면 오른쪽 메뉴를 실사용 흐름에 맞게 다시 짰습니다. 그 밖의 기능(USB 버튼 · Pro 검토 화면 포함)은 v1.18.3 과 같습니다.

- **멀티 화면 오른쪽 메뉴를 셋으로 (보정 · 편집 · 분석)**: Pro 검토 화면은 그대로입니다.
  - **편집** = 보기 → 도구(주석 · 측정) → 필터(노이즈 제거 · 선명하게 · 국소 대비) → 회전 · 반전. '필터' 탭을 편집에 합치고
    회전 · 반전을 맨 아래로.
  - **실행 취소 · 다시 실행 · 원본 · 주석 지우기 · 편집본 저장**은 메뉴 아래 늘 보이는 줄로 — 보정 · 분석 탭에서도 바로 누릅니다.
  - **스마트** 탭(LIVE 전용 자동 촬영 · 피킹)은 멀티에서 없앴습니다.
  - **분석 = 분석 + 정밀 분석 한 흐름**: '측정 종류' 하나 고르고(영상 품질 · 형광염색 · 결막 충혈 · 마이봄샘 · 수정체 혼탁 ·
    형광 염색 면적(빠른) · 충혈 지수(빠른) · 백내장 핵 · 피질) → '측정 실행' → 결과 → '코멘트에 기록' / '결과 영상 저장'.
    종류에 따라 필요한 것만 보입니다(충혈 민감도 · 마이봄샘 옵션 · 백내장 기록 칸). 멀티에서 쓸 수 없던 비교 화면 전용
    기능(고스트 · 위치 정렬 · 깜빡임 · 자동 정렬)과 LIVE 가이드는 뺐고, 가장 선명한 칸 · TBUT · DICOM 저장은 아래에 모았습니다.
  - 분석 탭 내용이 메뉴 폭보다 넓어 오른쪽 버튼이 잘리던 문제(제목이 길어 줄이 안 바뀜)도 고쳤습니다 (Pro 검토 분석 탭 포함).
- 웹 버전은 v1.18.3 과 같습니다.
