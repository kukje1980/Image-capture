# 다음 배포에 들어갈 변경 (아직 배포 안 함)

변경은 이 브랜치에만 모아 두고, **최종 배포 때** 버전 번호를 정해(앱 · 설치파일 · 웹 버전 파일, docs/RELEASE-x.y.z.md,
VERSIONS.md, README) main 에 합쳐 한 번에 배포한다. 배포하면 이 목록은 그 버전의 릴리스 노트로 옮기고 비운다.

마지막 배포판: v1.17.2 (2026-10-27)

- **차트번호(아이디) 중복 안내**: 신규 환자를 등록할 때 이미 있는 차트번호를 넣으면, 예전처럼
  'UNIQUE constraint failed' 오류를 띄우지 않고 등록된 환자(이름 · 생년월일 · 성별 · 진단명)를 보여 줍니다.
  - 이름이 다르면 "차트번호가 중복됩니다 — 등록된 환자 / 입력한 이름" 을 경고로 알리고,
  - **기존 환자로 계속**: 새로 등록하지 않고 기존 환자를 선택해 이어서 촬영합니다 (기존 환자 정보는 그대로).
  - **차트번호 다시 입력**: 등록 창으로 돌아가 번호를 고칩니다.
  - 정보 수정에서 다른 환자가 쓰는 차트번호로 바꾸려 하면 막고 알려 줍니다.
  - 기본판 · Keeler 판 · AI 에이전트 판 · Explorer 판 · Pro 검토 모두 같습니다.
- **검사 기록: 사진 골라 저장**
  - 사진을 **한 번 누르면 선택**(노란 테두리 + 고른 순서 번호), 다시 누르면 해제, **두 번 누르면 크게 보기**.
  - **전체 선택 / 선택 해제**, **선택 저장 (N)** — 고른 사진 · 동영상 원본만 고른 폴더에 저장
    (이름: 차트번호_촬영시각_안구_번호, 같은 이름이 있으면 _2 … 로 덮어쓰지 않음).
  - **인쇄 · PDF** 도 고른 사진이 있으면 그 사진만(고른 순서대로) 넣습니다. 고르지 않으면 예전처럼 그날 사진 전부.
  - 창 폭에 맞춰 한 줄의 사진 수가 바뀌고(좁으면 2장), 좁은 창에서는 위쪽 버튼이 아이콘만 남습니다.
- **멀티 버튼 위치**: 촬영 도크에서 빼고, 오른쪽 '촬영 이미지' 제목 줄 오른쪽(전체 · OD · OS 위)으로 옮겼습니다.
- **멀티 화면에서 Pro 검토 편집**: 고른 사진마다 Pro 검토와 같은 편집 캔버스이고, 위 편집 도구줄은 누른 칸(노란 테두리)에 적용됩니다.
  - 기본 도구는 **돋보기** — 사진을 누르고 있는 동안 확대 렌즈, 휠로 확대 · 축소.
  - 맞춤 · 확대 · 축소, 이동 · 텍스트 · 화살표 · 원 · 길이 · 각도, 왼쪽 · 오른쪽 회전 · 좌우 · 상하 반전,
    보정(밝기 · 대비 · 감마 · 채도 · 채널 · 선명하게 · 네거티브 · 자동 대비, '모든 사진에 같이 적용'),
    취소 · 다시 · 원본 · 지우기, **편집본 저장**(편집한 사진을 새 사진으로, 원본은 그대로).
  - 고른 사진이 바뀌어도 남아 있는 사진의 편집은 유지, '멀티 화면 저장' 에도 편집 · 주석이 들어갑니다.
  - 칸을 두 번 누르면(돋보기 · 이동 도구일 때) 큰 화면으로 봅니다.
- **촬영 도크 정리**: 가운데를 [분할 · 저장 · 정지영상] 한 묶음 → 셔터 → 녹화 → 전송 순서로 (분할 중에는 오른쪽에 '비우기').
  '저장' 은 묶음 안에 늘 보이고 분할 · 멀티일 때만 눌립니다. 셔터 위치는 어떤 모드에서도 그대로.
- **촬영 모드('기본') 를 설정으로**: 촬영 도크의 '모드/기본' 버튼을 없애고, 설정 → 일반 맨 위 '촬영 모드' 에서 고르게 했습니다
  (만들기 · 고치기는 '모드 만들기 · 편집…' → 촬영 모드 탭). 확인을 누르면 바로 바뀌고 아래 상태줄에 알려 줍니다.
