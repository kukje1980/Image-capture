# 다음 배포에 들어갈 변경 (아직 배포 안 함)

변경은 이 브랜치에만 모아 두고, **최종 배포 때** 버전 번호를 정해(앱 · 설치파일 · 웹 버전 파일, docs/RELEASE-x.y.z.md,
VERSIONS.md, README) main 에 합쳐 한 번에 배포한다. 배포하면 이 목록은 그 버전의 릴리스 노트로 옮기고 비운다.

마지막 배포판: v1.18.4 (2026-10-28) — [docs/RELEASE-1.18.4.md](RELEASE-1.18.4.md)

- **슬릿램프 사진 캡처 버튼 (버튼 3: Ctrl+Shift+Alt+F8)**: 촬영 도크 셔터와 같습니다 — 정지 화면이면 그 화면을, 아니면 라이브
  영상을 찍은 순간의 검사눈으로 저장. 길게 눌러도 한 장만, 환자가 없으면(셔터가 꺼져 있으면) 안내만.
- **슬릿램프 좌우 신호로 검사눈 자동 인식** (Windows 실장비 신호 확인: VID 04D9 / PID 1203 · MI_00, 좌우 신호 4: Ctrl+Shift+Alt+F6 → OD ·
  좌우 신호 5: Ctrl+Shift+Alt+F7 → OS). 기존 F9(녹화) · F10(스틸) 버튼은 그대로입니다. **실제 촬영 테스트 전이라 임상 사용 검증은 아닙니다.**
  - 신호는 토글이 아니라 늘 그 눈(F6 = OD · F7 = OS)으로 정하고, 직접 고를 때와 같은 함수(`ControlBar.set_eye`)를 거쳐
    화면 표시와 저장되는 사진의 검사눈이 같습니다. 이미 저장된 사진의 좌우는 바꾸지 않습니다.
  - 누름 한 번에 한 번 (자동 반복 · 뗌 없는 재누름 · 겹친 신호 무시), 촬영 화면이 앞에 있을 때만. 입력칸 · 다른 화면 · 설정 창에서
    받은 신호는 **보류**했다가 촬영 화면으로 돌아오면 적용합니다 (놓친 채 예전 눈으로 찍지 않게).
  - 촬영 도크 OD · OS 옆 상태 칩과 영상 HUD 눈 칩에 **미확인 · 자동 · 수동 · 확인 필요 · 정지 화면**이 보입니다. 처음 켰을 때 ·
    장치를 다시 꽂았을 때는 OD 로 짐작하지 않고 '미확인'(안구 미지정), 다른 프로그램에서 돌아오면 '확인 필요'.
  - 사진은 찍은 순간의 눈으로 고정: 정지 화면은 정지한 순간의 눈(정지 중 슬릿램프가 움직여도 그 사진은 그 눈, 직접 고치면 고친 눈),
    녹화는 시작한 눈으로 저장하고 녹화 중 전환은 영상 전체를 덮어쓰지 않고 코멘트에 시각과 함께 적습니다.
  - **장치 확인 (Windows Raw Input)**: `app/usb_raw_input.py` 가 WM_INPUT 으로 그 키가 VID 04D9 / PID 1203 · MI_00 장치에서
    왔는지 보고 다른 키보드의 같은 키 조합은 무시합니다. 장치를 다시 꽂으면 경로를 다시 읽고(꽂힘 · 빠짐 알림), 감시 키(F6 · F7 ·
    F9 · F10) 외의 글자 입력은 보지도 기록하지도 않습니다. 맥 · 등록 실패 시에는 예전처럼 모든 키보드 신호를 받습니다.
    **Windows 실장비에서는 아직 확인하지 못했습니다.**
  - 설정 → USB 버튼: 버튼 3 · 좌우 신호 4 · 5 의 키 · 기능, '좌우 자동 인식' 켜기 / 끄기, '장치 확인' 켜기 / 끄기, 신호 확인 칸에 장치 판정 표시.
