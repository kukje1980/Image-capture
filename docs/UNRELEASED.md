# 다음 배포에 들어갈 변경 (아직 배포 안 함)

변경은 이 브랜치에만 모아 두고, **최종 배포 때** 버전 번호를 정해(앱 · 설치파일 · 웹 버전 파일, docs/RELEASE-x.y.z.md,
VERSIONS.md, README) main 에 합쳐 한 번에 배포한다. 배포하면 이 목록은 그 버전의 릴리스 노트로 옮기고 비운다.

마지막 배포판: v1.18.0 (2026-10-27) — [docs/RELEASE-1.18.0.md](RELEASE-1.18.0.md)

- **슬릿램프 USB 버튼 2개 연결** (Windows 에서 확인한 장치: VID 04D9 / PID 1203, MI_00 키보드 인터페이스)
  - 버튼 1 `Ctrl + Shift + Alt + F9` → **녹화 시작 / 정지** (촬영 도크 '녹화' 와 같음).
  - 버튼 2 `Ctrl + Shift + Alt + F10` → **스틸 화면 정지 / 해제** (촬영 도크 '정지영상' 과 같음, 사진 파일은 저장하지 않음).
    분할 화면에서는 기존처럼 칸 채우기. 녹화 중에 눌러도 녹화는 계속되고 파일은 정상으로 닫힙니다.
  - 길게 눌러도 한 번만 — 자동 반복 · 뗌 없이 다시 온 누름은 무시하고, 뗀 뒤 다시 눌러야 다음 동작 (접점 튐 0.3초 안 겹침도 무시).
  - **촬영 화면에서만** 동작. 글자 입력칸(환자 검색 등) · 설정 · 안내 창 · 다른 프로그램에서는 실행하지 않습니다.
    입력칸에서 누르면 아래 상태줄에 알려 주고, 촬영 화면을 열면 · 검색칸에서 Enter 를 누르면 키보드 초점이 영상으로 갑니다.
  - **설정 → USB 버튼**: 두 버튼의 키 조합 · 기능(녹화 · 스틸 · 사진 캡처 · 사용 안 함)을 보고 바꾸기, '신호 확인' 칸에서 버튼을 눌러
    받은 신호 · 뗌을 확인. 같은 키를 두 버튼이나 단축키에 함께 쓰면 확인을 막고 알려 줍니다 (단축키 설정 창도 같은 검사).
  - 사진 촬영 버튼은 신호 확인 뒤 따로 정함 (지금은 배정 안 함). USB 드라이버 · 보드 설정은 바꾸지 않음.
  - 실제 USB 장치로는 아직 시험하지 않음 (같은 키 조합 이벤트로 검사). Explorer 판 창에는 아직 연결하지 않음.
