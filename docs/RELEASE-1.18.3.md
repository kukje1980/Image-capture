# SlitLamp v1.18.3

창이 화면보다 넓어지던 문제 수정과 멀티 화면 · 분석 편의 기능입니다. 그 밖의 기능(USB 버튼 포함)은 v1.18.2 와 같습니다.

- **상단바에 '환자 목록' 버튼**: 홈 · 촬영 · Pro 검토 · 검사 기록 옆에 '환자 목록' 을 두어 어느 화면에서든 바로 환자 목록 화면으로 갑니다
  (그 화면에 있으면 버튼이 켜짐 · 좁은 창에서는 다른 메뉴처럼 아이콘만).
- **창이 화면보다 넓어져 오른쪽(메뉴 · 사진 목록 · 멀티 버튼)이 잘리던 문제**: 코멘트가 아주 긴 사진(샘플 사진의 출처 · 주소 등)이 있는 환자를
  고르면, Pro 검토 MULTI 칸 아래 글자가 줄지 않아 창 최소 폭이 2000px 넘게 늘었습니다. 칸 글자를 한 줄 · 40자로 줄이고 폭을 늘리지 않게 했습니다.
- **멀티 '초기화' 버튼**: 멀티 화면일 때 촬영 도크 전송 옆에 '초기화' — 고른 사진 · 참조를 비우고 라이브 촬영 화면으로 ('멀티' 를 다시 누른 것과 같음).
- **오른쪽 클릭 = 멀티**: 오른쪽 사진 목록의 사진 위에서 오른쪽 클릭하면 (안 골랐으면 골라서) 바로 멀티 화면, 라이브 영상 위 오른쪽 클릭은 고른 사진으로 멀티.
- **크게 보기 창에 돋보기**: 사진을 두 번 눌러 여는 '보기' 창도 누르고 있으면 확대 렌즈 · 휠로 확대 · 축소, '이동' · '맞춤' 버튼.
- **충혈 민감도**: 분석 탭 '충혈 지수' 아래 '충혈 민감도' 1~10 (기본 5 = 예전 기준). 낮추면 더 붉은 곳만 표시 · 붉은 화소 % 가 줄고, 측정 뒤 움직이면
  바로 다시 측정합니다 (값 저장). 결과에 민감도를 함께 적고, 표시 레이어를 옅게 해 아래 조직이 보이게 했습니다. 붉은 표시가 넓으면(40% 이상) 민감도를
  낮추거나 '원' 으로 결막만 둘러 측정하라고 안내합니다. (충혈 지수 숫자는 측정 영역의 평균 붉은 기라 민감도와 무관 — '원' 으로 영역을 좁히면 바뀜)
- 웹 버전은 v1.18.2 와 같습니다.
