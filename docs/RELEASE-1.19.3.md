# SlitLamp v1.19.3

**촬영 화면 사진 목록에 여러 장이 보이고, 사진마다 OD · OS 가 크게 표시됩니다. 웹판에도 멀티 창이 들어갔습니다.**

윈도우 · 맥 앱
- 오른쪽 사진 목록을 **한 줄에 2장(기본) · 3장**씩, **최신 사진부터** 촬영일별로 보여 줍니다.
  필터 줄 오른쪽 **⊞ 2열** 버튼으로 1 → 2 → 3열을 고르고, 고른 값은 다음 실행에도 기억됩니다.
- 창이 좁으면(예: 1920×1080 · 150% 배율 = 1280px) 촬영 도크가 눌리지 않도록 자동으로 1열로 보이고, 창을 넓히면 고른 열 수로 돌아갑니다.
- 사진마다 위쪽 왼쪽에 **OD(파랑) · OS(주황) · OU(보라) · 미지정(회색)** 이 색이 채워진 큰 글자로 붙습니다.
- 멀티는 v1.18 그대로입니다: 사진 **클릭 = 선택**(번호) → **멀티** → 멀티 화면에서 보정 · 편집 · 분석. 오른쪽 클릭 = 멀티, 두 번 클릭 = 크게 보기.

웹
- 썸네일 격자(1~3열) · 사진 위 안구 배지 · **클릭 선택**(노란 테두리 + 번호, 최대 16장) · **멀티** 버튼 · **해제**.
  오른쪽 클릭 = 그 사진도 골라 바로 멀티, 두 번 클릭 = 크게 보기(다운로드 · 삭제), 동영상은 클릭하면 재생.
- **멀티 창**(화면 전체, Esc 로 닫기): 칸 클릭 = 편집할 영상, 더블클릭 = 1장 크게 ↔ 전체, ←/→ = 칸 이동.
  Pro 검토와 같은 **보정 · 필터 · 편집**(밝기 · 대비 · Red-free · 선명하게 · 회전 · 자르기 · 주석 · 길이/각도 측정 · 실행 취소),
  **보정 모두 적용** · **확대 동기화**, 선택 칸의 **안구(OD/OS) 수정** · **코멘트**, **편집본 저장**(원본 보존) · **인쇄 / PDF**.
  저장하지 않은 편집이 있으면 닫을 때 물어봅니다.
