# SlitLamp v1.9.1

v1.9.0 통합판의 화면 수정판입니다. 기능은 v1.9.0 과 같습니다.

- 데스크탑(맥·윈도우) Pro 검토 화면 오른쪽 패널의 탭 6개 — 보정 · 필터 · 편집 · **스마트 · 분석 · 정밀 분석** — 가
  한 줄에 들어가지 않아 뒤의 세 탭이 작은 ◀▶ 화살표 뒤로 숨어 있던 문제를 고쳤습니다. 이제 3×2 버튼으로 항상 모두 보입니다.
- 백내장 수정체 혼탁 지수: Pro 검토 → **분석** 탭 → 아래쪽 "백내장 — 수정체 혼탁 지수" (1화면에서 사용).

다운로드
- Windows: SlitLampImaging-Setup-1.9.1.exe (기본), KeelerSlitLamp-Setup-1.9.1.exe (Keeler).
- Mac: 기본/Keeler 각각 arm64(Apple Silicon)·x86_64(Intel) DMG.
- 웹: SlitLamp-Web-1.9.1.zip (웹 화면은 v1.9.0 과 같음 — 웹은 처음부터 탭이 두 줄로 모두 보임).
- 전체 소스: SlitLamp-Source-1.9.1.zip. SHA256SUMS.txt 로 무결성을 확인할 수 있습니다.

기존 데이터는 그대로 사용합니다. 영상 분석 결과는 참고 지표이며 진단이 아닙니다.
