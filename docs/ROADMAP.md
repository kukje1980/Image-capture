# 슬릿램프 영상 시스템 — 기능 로드맵

두 검토 자료(Smart Capture → Image Quality AI → 임상 분석 AI 순서 제안, 슬릿램프 AI 분석 기능 추천)의 기능을
**구현 가능한 순서**로 정리했습니다. 기준: 별도 학습 데이터·하드웨어 없이 바로 만들 수 있는 것부터 → 데이터·광학계·인허가가 필요한 것 순.

## v0.2.0 에 구현된 기능

| 순서 | 기능 | 기대 효과 | 구현 방식 | 위치 |
|:---:|------|-----------|-----------|------|
| 1 | **Smart Auto Capture** — 자동 정지 / 자동 저장 | 초점이 맞는 순간을 놓치지 않음 | ROI 선명도(Tenengrad) 정점·고원 검출, 쿨다운·재무장 | 촬영 화면 Smart 도구줄, Pro LIVE 툴바 |
| 2 | **Best Shot 버퍼** | 셔터 지연·흔들림 보정 | 최근 1초 프레임 중 가장 선명한 원본 | 사진 캡처, 자동 촬영 |
| 3 | **Focus Peaking** | 초점 맞추는 동안 즉시 확인 | 미세 구조(고역) 절대 문턱값, 반사광 테두리 제외 | 촬영 화면 |
| 4 | **ROI 지정** | 슬릿 조명 경계·속눈썹 오판 방지 | 영상 위 드래그(수동) | 촬영 화면 |
| 5 | **실시간 품질 표시** | 촬영 숙련도 차이 감소 | 초점·노출·안정(흔들림)·반사 점수 + 안내 문구 | 촬영 화면 |
| 6 | **저장 영상 품질 검사 · 가장 선명한 영상 찾기** | 흐린 영상 거르기 | 같은 품질 지표를 저장 영상에 적용, 선명도 순위 | Pro 분석 탭 |
| 7 | **이전 검사 비교 + 자동 정렬** | 병변 변화 추적 | ORB 특징점 + 유사 변환, 배율·밝기 차이 경고 | Pro 비교 + 분석 탭 |
| 8 | **DICOM 내보내기** | PACS·EMR 연동 | Ophthalmic Photography 8 Bit (OP), UTF-8 환자명 | Pro 분석 탭 |
| 9 | **형광염색 분석** | 각막 손상 면적·병변 수 정량화 | 녹황색 형광 색 분할(HSV + Otsu), Oxford 등급 근사 | Pro 분석 탭 |
| 10 | **TBUT 동영상 분석** | 눈물막 파괴 시간 자동 측정 | 깜빡임 검출 → 기준 대비 어두워진 반점 비율 추적 | Pro 분석 탭 |
| 11 | **결막 충혈 정량화** | 충혈 정도 기록·비교 | 녹색 채널 black top-hat 혈관 + 붉은기 지수, 참고 등급 0~4 | Pro 분석 탭 |
| 12 | **Meibography 분석** | 마이봄샘 탈락 정량화 | CLAHE + 국소 문턱값 + 세로 구조 필터, Meiboscore(Arita) | Pro 분석 탭 (IR 영상 필요) |
| 13 | **수정체 혼탁 지수** | 핵경화 경과 추적 | ROI 의 L*(밝기)·b*(황색도) 상대값 | Pro 분석 탭 |
| 14 | **리포트 연계** | 진료 기록 작성 시간 단축 | 분석 요약 → 코멘트, 결과 영상 → 기존 인쇄·PDF 보고서 | Pro 분석 탭 |

> 9~13 은 학습 모델이 아닌 **규칙 기반 참고 지표**입니다. 기준값(`app/analysis/clinical.py` 상단 상수)을
> 실제 임상 영상·전문가 판정으로 보정해야 하며, 판정은 의사가 오버레이를 보고 내립니다.
