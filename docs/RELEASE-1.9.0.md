# SlitLamp v1.9.0 통합판

v1.8.0 통합판 이후 병합된 변경을 모두 포함한 최종판입니다.

- 효과음: 사진 캡처·녹화 효과음을 실제 카메라 녹음으로 교체했습니다 (셔터, 녹화 시작/중지 — 데스크탑·웹 공통).
- 웹 Pro **스마트** 탭: 초점 판정, Best Shot(최근 프레임 중 가장 선명한 장면), 자동 정지/자동 저장, 포커스 피킹, 실시간 화질 점검.
- 웹 Pro **분석** 탭: 조명 태그, 형광 염색 면적, 충혈 지수, 경과 비교(고스트·위치 정렬·깜빡임), 백내장 핵/피질 혼탁 지수, LOCS III 입력, 경과 그래프.
  웹의 분석 계산은 브라우저 안에서만 하며 영상을 서버로 보내지 않습니다. TBUT·DICOM·마이봄샘 정밀 분석은 데스크탑 전용입니다.
- 데스크탑의 스마트 캡처·분석·정밀 분석·DB 안정성 기능은 v1.8.0 과 같습니다.

다운로드
- Windows: SlitLampImaging-Setup-1.9.0.exe (기본), KeelerSlitLamp-Setup-1.9.0.exe (Keeler).
- Mac: 기본/Keeler 각각 arm64(Apple Silicon)·x86_64(Intel) DMG.
- 웹: SlitLamp-Web-1.9.0.zip 의 web/ 폴더 (Vercel·Render 는 main 에서 자동 배포).
- 전체 소스: SlitLamp-Source-1.9.0.zip. SHA256SUMS.txt 로 무결성을 확인할 수 있습니다.

기존 데이터는 보존합니다 (웹의 '이 PC에만 저장' 저장소도 자동 업그레이드). 설치 전 기존 DB와 미디어 폴더 백업을 권합니다.
영상 분석 결과는 촬영 조건에 영향을 받는 참고 지표이며 진단이 아닙니다. 실장비·실영상 검증은 별도로 확인해야 합니다.
