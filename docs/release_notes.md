## 안저 사진 뷰어 — 최신 빌드 (Windows)

아래 **Assets** 의 **FundusViewer-windows.zip** 을 눌러 내려받으세요 (Windows 10 / 11, 로그인 필요 없음).

### Windows 설치·실행
1. 내려받은 zip 파일의 압축을 풉니다.
2. `FundusViewer` 폴더 안의 **FundusViewer.exe** 를 실행합니다.
3. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행** 을 누릅니다 (서명하지 않은 프로그램이라 나오는 경고입니다).

### 버전 0.2.1 — 3D 안구는 원본 사진 그대로
* **3D 안구**가 처음에 촬영한 **원본 사진 그대로** 망막에 얹어 보여 줍니다. 혈관을 솟게 하고 음영을 더하던
  **망막 입체**(표면 높낮이 · 입체 조명)는 기본으로 꺼 두었습니다. 필요하면 3D 안구 탭 → 설정 → **망막 입체**에서 켭니다.
  이전 버전에서 켜진 채 쓰던 설정은 이 버전을 처음 열 때 한 번 꺼집니다. 몽타주 창의 3D 미리보기도 같습니다.

### 버전 0.2.0 — 환자 목록 · 검토 화면 · 환자 설명
* **환자 목록 (처음 화면)**: 프로그램이 환자 목록에서 시작합니다. 검색, 전체 / 오늘 / 최근 7일, 환자 표(검사 수 · 영상 수),
  오른쪽에 환자 카드와 **검사 목록**(검사일별, 체크한 검사가 현재 검사). 환자를 두 번 누르면 검토 화면이 열리고,
  작업 화면의 **‹ 환자 목록**(Ctrl+0)으로 돌아옵니다. 새 사진이 들어오면 전처럼 그 환자의 사진이 바로 열립니다.
* **검토 탭** (Ctrl+6): 처음에는 **양안**(OD | OS) 두 장, 배치 목록에서 **이전 검사 비교**(OD 비교 · OS 비교 — 이전 | 현재,
  `[` `]` 로 더 이전 검사). 아래 **타임라인**(모두 · OD · OS)에서 사진을 **눌러 고르면 고른 사진만큼** 화면이 나뉘고
  (1 · 2 · 4 · 8 · 16 · 32장, 사진 수 단추로 직접 정할 수도 있음), **◀ ▶**(← →)로 다음 사진들로 넘기며, **더블클릭**하면 한 장만
  크게 보고 다시 더블클릭하면 돌아옵니다. 화면으로 끌어다 놓기, 날짜를 누르면 현재 검사. **연동**(모든 화면의 확대 · 이동을 함께),
  **확대창**(가운데 클릭, 휠 1.5×–6×, 오른쪽 클릭 = 다음 화면의 같은 곳), 보기(컬러 · 감각망막 · 맥락막).
  선택한 화면의 사진을 **2D 보기 · 3D 안구 · 녹내장**으로 넘깁니다.
* **작업 화면의 환자 창**은 처음에 닫혀 있고 명령 툴바의 **환자 창**(또는 환자 검색)으로 엽니다 — 사진 화면이 넓어집니다.
* **녹내장 분석 → 환자 설명**: 정상 · 초기 · 중기 · 말기 단계별 시신경 유두 모식도와 **환자가 보는 시야 (예시)**, 설명 글.
  설명용 모형이며 이 환자의 실제 진행 단계를 뜻하지 않습니다.
* `--demo` 데모 환자 김민수(20260115001)에 이전 검사 두 번을 넣어 비교 배치를 바로 써 볼 수 있습니다.
* **몽타주 자동 합치기 — 실제 광각 사진**: 화각과 렌즈 곡선을 사진들에서 찾아 맞추고(`렌즈 보정 176° → 110°`), 눈꺼풀 반사와
  렌즈 플레어 점은 합칠 때 뺍니다. 혈관이 겹쳐 흐려지던 것과 밝은 띠·점이 섞이던 것이 줄어듭니다.
* **3D 안구**: 공막(흰 벽)을 얇게 그립니다 — 잘린 면의 흰 테두리가 절반쯤으로 줄었습니다.
* **몽타주 속도**: 자동 합치기가 빨라졌고(렌즈 보정 찾기 · 반사 가리기), **빠르게 저장**을 켜면 저장하는 그림을 2400픽셀로 그려
  시간이 절반 아래로 줄어듭니다.
* **몽타주 자동 합치기**: 흐리거나 잡음이 많고 혈관이 옅은 사진도 더 잘 맞춥니다(혈관만 남긴 그림에서 한 번 더 찾고,
  안 되면 느슨한 조건으로 다시 시도). 못 맞춘 사진은 전처럼 손으로 옮기거나 기준점으로 맞춥니다.

### 녹내장 분석
사진 목록 왼쪽의 **[녹내장]** 을 누르면 보고 있는 사진으로 분석 창이 열립니다.
* **디스크 C/D**: 시신경 유두 주변을 잘라 보여 주고, 디스크 · 컵 타원을 맞추면 수직 · 수평 · 면적 C/D, 림 두께(ISNT)가 나옵니다.
* **광각 분석**: 레드프리 + RNFL 대비 강화, Garway-Heath 구역, 시야검사 24-2 격자. 누른 곳의 시계 방향 · 구역 · 대응 시야를 알려 줍니다.
* **스테레오 보기 · 경과 비교**: 두 번째 사진을 **Ctrl+클릭**(②)한 뒤 [녹내장]을 누르면 위글 · 나란히 · 적청 · 깊이 지도,
  깜빡임 · 겹치기 · 변화 지도로 두 장을 비교합니다 (유두 중심으로 같은 망막 범위에 맞춤).
* 분석 화면은 환자 기록에 새 사진(`녹내장 분석`)으로 저장하거나 파일 저장 · 복사할 수 있습니다. 측정값은 참고용 추정값입니다.

### 3D — 들어가며 보기 · 망막 입체 · 슬릿 네 방향 · 단순하게 보기
* **들어가며 보기**: 안구 전체에서 각막 → 앞방 → 동공 → 수정체 → 유리체 → 망막까지 어두워지지 않고 이어서 들어갑니다
  (설정 → 들어가며 보기의 ▶ 들어가기 · 위치 막대, 위 막대의 외부 | 내부). 지나는 곳 이름이 안구 아래에 뜹니다.
  사진 펼치기는 없앴습니다.
* **망막 입체 → 표면 높낮이**(0.2.1부터 기본 꺼짐): 혈관은 솟고 시신경 유두의 함몰과 황반의 오목은 파이도록 망막 표면을 실제로
  올리고 내립니다. 안구를 돌리면 높낮이가 보이고, **높이**로 크기를 정합니다. 안구 안쪽은 그림자 없이 고르게 밝습니다.
* **슬릿 스캔 방향**: ↓ 위에서 아래로 · ↑ 아래에서 위로(세로 단면), → · ←(앞을 연 안구의 망막 위로), **상하좌우**(차례로).
* **단순하게 보기**(설정 → 표시): 공막·홍채·수정체·시신경을 단순하게 그려 망막을 강조합니다.
* 눈(OD/OS)을 알 수 없는 사진은 황반을 시신경 유두 양쪽에서 찾고, 황반이 있는 쪽으로 눈을 정합니다.

### 3D — 황반과 시신경 유두를 실제 위치에
사진에서 **황반**과 **시신경 유두**를 찾아, 황반은 안구 뒤쪽 한가운데(후극)에, 유두는 코쪽 제자리(황반에서 약 4.5 mm)에 오도록
사진을 얹습니다. 유두 중심으로 찍었거나 옆·위를 보고 찍은 사진도 **망막의 실제 위치**에 놓이고, 크기는 사진의 **화각**대로입니다
(45° 사진은 작은 부분, 176° 사진은 뒤쪽 대부분). 3D 안구 탭 → 설정 → 사진 맞춤 아래에 어떻게 맞췄는지와 사진에서 잰
황반–유두 거리가 나옵니다. 잘못 찾았으면 2D 사진에서 **오른쪽 클릭 → 황반 / 시신경 유두로 지정**, 끄려면 **실제 위치에 맞춤**.

### 사진 위 글자
사진 위에 환자 이름·ID·날짜를 초록색 글자로 쓰던 것을 없앴습니다. 구석에 사진 번호와 눈(OD/OS)만 작게 나옵니다
(보기 → 화면 글자 표시로 끌 수 있음).

### 새 화면 — 어둡고 차분하게
화면 전체를 **어두운 화면**(아이폰 다크 모드 방식)으로 다시 만들었습니다. 고른 것과 주 버튼만 파란색, 켜고 끄는 항목은
**스위치**, 둘 중 하나를 고르는 항목은 **나란한 단추**이고 탭을 바꾸면 화면이 겹쳐 넘어갑니다. 창 제목 표시줄도 어둡습니다.

**3D 안구 탭**은 위에 막대 한 줄(`간단히 | 자세히` · `외부 | 내부` · ▶ 슬릿 스캔 · 크게 보기 · 설정)만 남기고,
나머지는 오른쪽 **설정 패널**에 시점 / 안구 열기 / 효과 / 표시 / 사진 맞춤으로 묶었습니다(설정 버튼으로 열고 닫음).

### 3D — 유리 같은 공막, 진한 망막
**공막 투명도**(설정 패널 → 안구 열기, 기본 80): 공막이 유리처럼 비쳐 보이고 **사진이 있는 망막은 진하게 그대로** 남습니다.
안구를 돌리면 뒤에서도 옆에서도 망막이 안구 속 어디에 있는지 입체로 보입니다. 0으로 내리면 예전의 흰 공막입니다.
처음 열면 **자세히** 모형이 **천천히 돌고** 있습니다(자동 회전 — 만지면 멈춤, 효과에서 끌 수 있음).

### 모두 보기 (첫 화면)
왼쪽에 큰 사진, 오른쪽에 다중(4장) · 확대(처음엔 시신경 유두 ×4, 큰 사진을 클릭한 곳) · 3D 안구가 함께 나옵니다.
칸 제목을 누르면 그 화면을 크게 엽니다.

### 사진 목록 · 멀티 (VK-2 방식)
사진 목록은 최신 사진부터 나오고, 사진마다 왼쪽 위에 **OD(파랑) · OS(주황)** 가 붙습니다. 사진 목록은 화면 아래쪽에 있고, 왼쪽의 **▤** 버튼으로 1·2·3줄.
사진을 **클릭**하면 멀티로 골라지고(노란 번호), **더블클릭**하면 2D로 크게 열립니다. **[멀티]** 를 누르면 고른 사진이
다중 보기에 모이고, 칸을 누르면 **그 사진만** 아래 툴바로 보정됩니다(Red-free · 대비 · 선명하게 …).

### 몽타주 — 여러 장을 한 장으로, 3D 안구에서 보기
같은 눈의 사진을 2장 이상 클릭해 고르고 사진 목록 왼쪽의 **[몽타주]** 를 누르면 겹치는 혈관을 찾아 **자동으로 합칩니다**.
맞추기 화면에서는 고른 사진이 **반투명**하게 겹쳐 보여 드래그로 옮기고(Ctrl+드래그 = 돌리기) 맞출 수 있고, **기준점으로
맞추기**에서 두 사진의 같은 혈관 갈림길을 찍어 맞출 수도 있습니다. 밝기를 맞추고 경계 없이 섞은 결과를 **3D 안구**에
입혀 보며, 몽타주의 각도(안구 중심각)는 자동으로 계산되고 직접 정할 수도 있습니다. **환자 기록에 저장**하면 사진 목록에
`몽타주`로 추가됩니다(오른쪽 클릭 → 몽타주 다시 편집).

### 사진 확대·축소
도구를 고를 필요 없이 사진 위에서 **위로 드래그하면 확대, 아래로 드래그하면 축소**됩니다 (누른 곳 중심).
이동은 가운데 버튼(휠) 드래그나 [이동] 도구, 더블클릭은 화면 맞춤입니다.

### 부드럽고 빠르게
돌리다 놓으면 3D 안구가 **관성**으로 더 돌다가 멎고, 휠 확대는 2D·3D 모두 **미끄러지듯** 이어집니다. 2D 사진도 끌다 놓으면
더 밀리고, 다음 사진은 겹쳐 넘어갑니다(**보기 → 부드러운 움직임**으로 끌 수 있음). 큰 사진(2,400만 화소)에서 사진 넘기기는
0.4초 → 0.07초, 3D 준비는 1.5초 → 0.06초, 밝기·대비 조정은 0.2초 → 0.01초로 빨라졌고, 그래픽카드가 없는 PC의 3D도 2배 이상
빨라졌습니다.

### 3D 효과
**입체 조명**(혈관·시신경 유두가 도드라져 보임), **들어가며 보기**(내부를 누르면 각막·동공·수정체를 지나 안으로),
**자동 회전**을 3D 안구 탭의 막대와 설정 패널에서 켭니다.

### 3D 안구 — 슬릿 스캔
3D 안구 탭의 **▶ 슬릿 스캔** 을 누르면 사진이 안구 옆에 나란히 나오고, 옆에서 반으로 자른 안구에 화각(예: 176°)이 표시된 뒤
슬릿이 사진을 위에서 아래로 훑으며 빛이 동공을 지나 같은 망막 위치에 닿는 모습을 보여 주고, 사진을 입힌 3D 안구로 돌아갑니다.
**세로 단면**(안구를 옆에서 자른 모습)과 **망막 투시**(사진을 입힌 망막을 안구 밖에서 보기)는 따로 켤 수도 있고,
**크게 보기**로 화면 전체에 띄울 수 있습니다(Space = 다시 재생, Esc = 돌아가기).

### 사진 가져오기
설정할 것이 없습니다. 실행하면 레티캠(`reticam`·`레티캠`) 등 장비 폴더와 `문서\안저사진 가져오기` 폴더를 찾아 자동으로 감시하고, 새 사진의 환자 ID·이름을 읽어 환자별로 정리합니다.

가상 데모 사진으로 먼저 써 보려면 명령 프롬프트에서 `FundusViewer.exe --demo` 로 실행합니다 (몽타주는 데모 환자 `D0001240`).
