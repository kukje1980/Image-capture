# SlitLamp v1.15.0

기본판(SlitLampImaging) · Keeler 판 · AI 에이전트 판의 촬영 화면을 사용하시는 분 의견대로 고쳤습니다. Explorer 판은 v1.14.0 과 같습니다.

**버튼 · 화면 정리**
- 위쪽 메뉴 · 촬영 도크 · 홈 타일 버튼을 v1.12.1 까지 쓰던 버튼 방식으로 다시 만들어, 일부 PC 에서 눌러도 반응이 없던 문제를 고쳤습니다. 버튼 동작에서 오류가 나면 안내창이 뜨고 `logs/app.log` 에 남습니다.
- 카메라 다시 연결 · 단축키 · 샘플 사진 · 화면 테마를 **설정** 창으로 옮겼습니다 (설정은 일반 · 카메라·저장 · 전송 · 촬영 모드 탭).
- 환자 검색 · 선택 칸을 맨 위 '정보 수정' 옆으로 옮기고, 실시간 화면에 이미 보이는 환자 정보 줄은 없앴습니다.
- 홈의 **환자 목록** 타일(또는 L 키)은 환자 목록 화면(검색 · 사진 수 · 최근 촬영, 두 번 누르면 촬영 시작)을 엽니다.
- 촬영 도크는 가운데(정지영상 · 셔터 · 녹화)가 어떤 모드에서도 제자리이고, 버튼 글자가 바뀌어도 위치가 움직이지 않습니다.
- 녹화 오른쪽 실시간 안내 글자를 없앴습니다. 일시정지 버튼은 정지영상(누르면 멈춤 · 다시 누르면 라이브)과 같아 하나로 합쳤습니다.
- 안구 선택에서 OU 를 없앴습니다 (이미 저장된 OU 영상은 그대로 보입니다). 사진 목록의 '동영상' 분류를 없앴습니다.
- **Smart 줄**은 오른쪽 끝 ▾ 로 숨기고, 도크의 'Smart' 버튼으로 다시 보입니다.

**사진 고르기 · 멀티 · 분할 · 전송 · 촬영 모드**
- 오른쪽 사진 목록: **한 번 누르면 선택**(번호 표시), **두 번 누르면 크게 보기**. 설정에서 **OD · OS 나눠 보기**를 켤 수 있습니다.
- **멀티**: 고른 사진을 한 화면에 모아 보기 · 한 장으로 **저장** · 다시 누르면 선택 초기화.
- **분할**: 누르면 **2 · 4 · 6 · 8 · 16칸** 중에서 고르고, 고른 칸 수는 저장됩니다. 끄고 켜면 초기화, 칸이 다 차면 '처음부터'.
- **전송**: 고른 사진을 **폴더**(네트워크 공유 폴더 포함) · **클라우드 동기화 폴더**(OneDrive · Google Drive · Dropbox · iCloud) ·
  **PACS (DICOM C-STORE)** 로 보냅니다. 형식은 원본 · JPG · PDF 보고서 · DICOM 중에서 고르고, 방법 · 위치 · 기본 형식은 설정 → 전송.
- **촬영 모드**: 자주 쓰는 카메라 · 촬영 설정(해상도 · 노출 · 게인 · 밝기 · 대비 · 채도 · 선명도 · 화이트밸런스 · Smart · 피킹 · 분할)을
  이름 붙여 저장하고, 도크의 **모드** 버튼으로 촬영 중에 바로 바꿉니다. 설정 → 촬영 모드에서 추가 · 복제 · 삭제 · 미리보기.

기존 데이터 · 설정은 그대로 씁니다. 카메라 조정값 지원 범위와 PACS 연결은 실장비 · 병원 PACS 에서 한 번 확인하세요(설정 → 전송 → 연결 확인).
