# SlitLamp v1.11.0 — AI 에이전트 에디션

같은 소스에서 **기본 에디션**과 **AI 에이전트 에디션**(`SlitLampAgent`) 두 프로그램을 만듭니다. 두 에디션은 데이터 폴더가
달라 같은 PC 에 나란히 설치됩니다. 기본 에디션은 이전 버전과 같고, **설정 → AI 에이전트** 로 같은 기능을 켤 수도 있습니다.

## AI 에이전트 에디션 (새 기능)
- **장면 인식**: 확산광 전안부 / 슬릿 단면 / 후방조명 / 형광염색 / 적외선 마이봄 / 외안부 / 판독 불가 를 실시간 판정 (슬릿 폭·각도 추정).
  규칙 기반이 기본, 학습 모델(JSON/ONNX)이 있으면 우선.
- **자동 촬영**: 장면이 안정되고 초점·흔들림 조건이 맞으면 눈·장면당 한 장을 자동 저장 (이유가 로그와 상태줄에 남음).
- **프로토콜 체크리스트**: 기본 전안부 / 백내장 / 건성안·각막 / 마이봄샘 — 필요한 샷을 안내하고 ✓ 표시.
- **촬영 전후 클립**: 사진을 찍는 순간 앞 4초 + 뒤 2초를 mp4 로 함께 저장.
- **추천 프레임**: 전후 구간의 초점 상위 4장을 썸네일로 제시, 클릭하면 저장.
- **사용 데이터 수집(익명)** 과 **학습 데이터 내보내기** — 병원에서 쌓인 사진·선택 기록으로 재학습.
- 학습 도구 `tools/agent_train/` (공개 데이터 → 모델, 병원 데이터 재학습, CNN/ONNX). 방법은 `DATASETS.md`.

에이전트는 촬영 보조만 하며 진단·소견을 내지 않습니다. 모든 처리는 PC 안에서만 일어납니다.

## 다운로드
- Windows: SlitLampImaging-Setup-1.11.0.exe (기본), KeelerSlitLamp-Setup-1.11.0.exe (Keeler), **SlitLampAgent-Setup-1.11.0.exe (AI 에이전트)**.
- Mac: 기본/Keeler/**에이전트** 각각 arm64(Apple Silicon)·x86_64(Intel) DMG.
- 웹: SlitLamp-Web-1.11.0.zip (웹 버전에는 에이전트가 아직 없습니다).
- 전체 소스: SlitLamp-Source-1.11.0.zip. SHA256SUMS.txt 로 무결성을 확인할 수 있습니다.

기존 데이터는 그대로 사용합니다 (DB 에 `agent_events` 테이블이 추가됩니다).
