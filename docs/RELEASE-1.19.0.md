# SlitLamp v1.19.0

**질환별 샘플 사진이 설치파일에 기본으로 들어 있습니다** (기본판 · Keeler 판 · AI 에이전트 판 · Explorer 판, 윈도우 · 맥).

- 처음 실행하면 샘플 사진 26장(11개 질환: 정상 대조 · 건성안 · 안검염/MGD · 결막염 · 백내장 · 다래끼 · 결막하출혈 · 익상편/검열반 ·
  각막미란/이물 · 감염각막염 · 백내장 수술 후 후낭혼탁)이 자동으로 등록됩니다. 따로 폴더를 받아 '샘플 사진 가져오기' 를 할 필요가 없습니다.
  - 환자 목록의 `샘플 · 질환명 (SAMPLE-NN)` 환자, 참조 영상의 '샘플 사진', 멀티 화면 '참조' 줄에서 바로 보고 환자 사진과 비교할 수 있습니다.
  - 사진은 원본 그대로이며 원문 진단 · 출처 · 라이선스 · 저해상도 · 외상 여부가 영상 코멘트에 있습니다. 등급은 붙이지 않았습니다.
  - 한 번만 등록합니다. 예전에 직접 가져온 사진은 중복으로 건너뛰고, 샘플 환자를 지우면 다시 넣지 않습니다.
- **이용 조건**: 24장은 EyeRounds 의 CC BY-NC-ND 3.0 사진이라 **비영리(병원 내부 교육 · 참고)용**으로만 쓰고, 판매 · 유료 제공 등 상업적으로 배포하지 마세요.
  자세한 출처는 설치 폴더의 `assets/samples/출처_및_이용조건.txt` 에 있습니다. LOCS III 도표 1장은 도표 원저작 권리를 별도로 확인해야 합니다.
- **동영상 화질**: 설정 → 동영상 화질에서 일반 / 고화질을 고릅니다 (기본 일반). 4K 녹화도 끊기지 않게 인코더 속도를 해상도에 맞췄습니다.

다운로드
- Windows: SlitLampImaging-Setup-1.19.0.exe (기본), KeelerSlitLamp-Setup-1.19.0.exe (Keeler), SlitLampAgent-Setup-1.19.0.exe (AI 에이전트) 등.
- Mac: 각 판 arm64(Apple Silicon) · x86_64(Intel) DMG.
- 설치파일이 샘플 사진만큼(약 16MB) 커졌습니다. 기존 데이터는 그대로 사용합니다.
