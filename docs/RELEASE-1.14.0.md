# SlitLamp v1.14.0

새 판 **Explorer 판(SlitLampExplorer)** 을 추가했습니다. 같은 엔진(카메라·저장·DB·Pro 보정)에
메뉴바 · 툴바 · 환자 › 검사 트리 · 썸네일 목록 화면을 얹고, 세극등 영상 시스템에서 많이 쓰는 기능을 더했습니다.
기본판 · Keeler 판과 나란히 설치되고 환자 DB·영상은 같은 데이터 폴더를 함께 씁니다.

- **환자 › 검사 트리**: 검사(내원) 단위로 영상을 묶음. 캡처는 고른 검사에, 환자만 골랐으면 오늘 검사가 자동으로 만들어짐.
  기존 영상은 촬영 날짜별 검사로 자동 정리. 검색 항목 전체 / 이름 / 차트번호 / 진단명 / 병력·소견(검사 기록 소견 포함).
- **겹쳐보기**: 다른 날 찍은 2장을 겹치기(투명도) · 차이 강조 · 바둑판 · 좌우 분할로 비교, 위치 맞춤, 겹친 영상 저장.
- **비교**: 2~4장 나란히, 확대·이동 동기화, 채널(Red-free 등)·밝기·대비 일괄 적용.
- **참조 영상 라이브러리**: 분류 · 제목 · 설명과 함께 등록(사본 보관), 현재 환자 영상과 나란히 비교.
- **슬라이드쇼**, **보고서**: Word(.docx, 편집 가능) · PDF(소견 기입) · 인쇄.
- **카메라 속성**: 자동 노출 · 노출 · 게인 · 밝기 · 대비 · 채도 · 선명도 · 자동 WB · 색온도를 장치에 바로 적용하고 저장
  (캡처보드·드라이버가 지원하지 않는 항목은 '미지원' 표시).
- **파일**: 영상 가져오기 · 내보내기 · 삭제, DB 백업 / 복원.
- 기본판·Keeler·AI 에이전트 판의 화면과 기능은 그대로입니다 (새 `exams` · `ref_images` 테이블은 처음 실행할 때 자동으로 추가).

다운로드

  **SlitLampExplorer-Setup-1.14.0.exe (Explorer 판)**, SlitLampAgent-Setup-1.14.0.exe (AI 에이전트).
