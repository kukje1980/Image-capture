# SlitLamp v1.10.0

웹 버전 Pro 화면 개선과 참조 샘플 비교 기능을 추가했습니다.

- **탭 메뉴를 위로**: 보정 · 필터 · 편집 · 마이봄 · 스마트 · 분석 · 참조 탭이 Pro 상단 도구줄에 있습니다. 오른쪽 패널은 선택한 탭의 내용만 보여줍니다.
- **참조 탭 (새 기능)**: 부위(안검·결막·각막·전방·홍채·수정체·마이봄샘·기타)별로 **정상 / 비정상(질환명)** 대표 영상을 참조 샘플로 저장해 두고,
  - **현재 영상과 비교**: 1화면에서 보던 영상(왼쪽)과 선택한 샘플(오른쪽)을 나란히
  - **정상 샘플과 비교**: 같은 부위의 정상 샘플(왼쪽)과 현재 영상 또는 선택한 비정상 샘플(오른쪽)을 나란히
  - 등록: 1화면의 현재 영상, 또는 PC 의 영상 파일(교과서·다른 장비 사진 등)
  - 정상/비정상·질환명은 사용자가 붙이는 분류이며 프로그램이 판정하지 않습니다.
- 데스크탑 앱(맥·윈도우)은 v1.9.1 과 같습니다 (탭 3×2 표시 포함).

다운로드
- Windows: SlitLampImaging-Setup-1.10.0.exe (기본), KeelerSlitLamp-Setup-1.10.0.exe (Keeler).
- Mac: 기본/Keeler 각각 arm64(Apple Silicon)·x86_64(Intel) DMG.
- 웹: Vercel·Render 는 main 에서 자동 배포. 직접 올릴 때는 SlitLamp-Web-1.10.0.zip.
- 전체 소스: SlitLamp-Source-1.10.0.zip. SHA256SUMS.txt 로 무결성을 확인할 수 있습니다.

기존 데이터는 그대로 사용합니다 (웹 '이 PC에만 저장' 저장소는 자동 업그레이드).
