# SlitLamp v1.13.0

데스크탑 앱(맥·윈도우) Pro 검토 화면에 **샘플과 비교**를 추가했습니다.

- Pro 검토 → 위쪽 **샘플과 비교** → 질환을 고르고 샘플 사진을 고르면, 왼쪽에 지금 환자 영상, 오른쪽에 샘플 사진이 나란히 나옵니다.
- 확대·이동이 양쪽에 함께 적용되고, 보정·겹쳐 보기·깜빡임 전환·인쇄도 그대로 쓸 수 있습니다.
- 환자 진단명과 같은 질환이 먼저 열리고, 사진마다 원문 진단·출처·라이선스가 보입니다.
- 샘플 사진은 참고용이며 진단이 아닙니다. 편집본·분석 결과·DICOM 내보내기로 환자 영상에 저장되지 않습니다.
- 샘플 사진은 v1.12.0 부터 있는 상단 **샘플** 버튼으로 먼저 가져와야 합니다. 웹 버전은 v1.11.0 과 같습니다.

다운로드
- Windows: SlitLampImaging-Setup-1.13.0.exe (기본), KeelerSlitLamp-Setup-1.13.0.exe (Keeler), SlitLampAgent-Setup-1.13.0.exe (AI 에이전트).
- Mac: 기본/Keeler/에이전트 각각 arm64(Apple Silicon)·x86_64(Intel) DMG.
- 웹: SlitLamp-Web-1.13.0.zip. 전체 소스: SlitLamp-Source-1.13.0.zip. SHA256SUMS.txt 로 무결성을 확인할 수 있습니다.

기존 데이터는 그대로 사용합니다.
