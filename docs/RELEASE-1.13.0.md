# SlitLamp v1.13.0

화면을 아이콘 중심으로 단순하게 바꾸고, 홈 화면과 검사 기록 화면을 더했습니다 (데스크탑 맥·윈도우 + 웹 공통).

- **상단 아이콘 메뉴**: 홈 | 촬영 | Pro 검토 | 검사 기록 | 신규 환자 | 정보 수정, 오른쪽에 카메라·단축키·샘플·설정·테마. 환자 배너는 요약과 검색·선택만 남겨 정리했습니다.
- **홈(시작) 화면**: 큰 아이콘 타일(신규 환자·환자 목록·촬영·Pro 검토·검사 기록·설정)로 바로 가기. "다음부터 촬영 화면으로 바로 시작"을 켜면 건너뜁니다.
- **검사 기록 화면**: 촬영일별 목록 → 그날의 영상 모음 + **검사 소견**(검사 종류 서식 자동 채움, 칸을 벗어나면 자동 저장) + 환자 정보. 인쇄·PDF 보고서에 소견이 함께 들어갑니다. 웹은 `/api/v1/patients/{id}/exams` API 로 같은 기능을 제공합니다.
- **생년월일 입력**: 달력에서 고르거나 숫자만 입력(`19800315`, 주민번호 앞자리 `800315`, `1980.3.15`)하면 자동으로 정리됩니다.
- 촬영 도크를 아이콘 버튼으로 바꾸고 사진 캡처는 원형 셔터 버튼으로 두었습니다. 기존 기능(Smart 도구줄·AI 에이전트·샘플 가져오기·효과음 등)은 그대로입니다.

다운로드
- Windows: SlitLampImaging-Setup-1.13.0.exe (기본), KeelerSlitLamp-Setup-1.13.0.exe (Keeler), SlitLampAgent-Setup-1.13.0.exe (AI 에이전트).
- Mac: 기본/Keeler/에이전트 각각 arm64(Apple Silicon)·x86_64(Intel) DMG.
- 웹: SlitLamp-Web-1.13.0.zip. 전체 소스: SlitLamp-Source-1.13.0.zip. SHA256SUMS.txt 로 무결성을 확인할 수 있습니다.

기존 데이터는 그대로 사용합니다 (검사 소견 테이블은 처음 실행할 때 자동으로 추가됩니다).
