# 컵 경계 찾기 — 혈관 꺾임 · 하이브리드 방식의 방법과 측정 (0.13.21)

녹내장 분석 창이 사진 한 장에서 **컵 경계**를 스스로 그리는 방식 가운데 **혈관 꺾임**과 **하이브리드**를 0.13.21에서
바꾸었고, 전문가가 디스크와 컵을 그려 둔 실제 사진으로 정확도를 재었습니다. (**밝기** 방식은 그대로입니다.)

## 왜 바꾸었나
전의 혈관 꺾임 방식은 "혈관이 급하게 꺾이는 점"을 규칙으로 찾아 그 점들을 이은 선을 컵 경계로 삼았습니다. 재어 보니

* 꺾임은 사진 한 장에 평균 **1개**밖에 찾지 못했고, 38 %의 사진에서는 하나도 찾지 못했습니다.
* 그래서 혈관 꺾임 방식은 시험용 사진의 **85 %에서 컵을 그리지 못했습니다**(꺾임이 모자라면 그리지 않도록 되어 있었음).
* 찾은 꺾임도 전문가의 컵 경계에서 디스크 반지름의 0.1 이내에 있는 것은 **40 %**뿐이었습니다(컵을 늘 같은 크기로 어림해도
  56 %가 그 안에 듭니다).
* 하이브리드는 꺾임이 모자라면 밝기 방식으로 돌아가므로, 대부분의 사진에서 밝기 방식과 같았습니다 — 컵을 작게 읽습니다
  (수직 C/D가 평균 0.09 작음).

## 바꾼 방법
꺾임 **한 점 한 점** 대신 디스크를 빙 둘러 **혈관이 지나는 모양**(어디에 몰려 있고 어디서 퍼지는지)과 **밝기가 떨어지는 모양**을
읽습니다(`fundusview/cuplearn.py`).

1. 디스크 경계(사진에서 찾은 것, 없으면 예상 크기의 원)를 기준으로 72 방향 × 32 단계의 띠를 읽습니다 — 방향마다 디스크
   가운데에서 그 방향 디스크 반지름의 1.28배까지. 디스크가 크든 작든 같은 모양으로 읽힙니다.
2. 띠마다 세 가지: 혈관을 지운 녹색 · 빨강의 밝기(그 사진의 범위에 맞춰), 그리고 혈관이 있는 정도.
3. 방향마다 "컵이 디스크 반지름의 몇 할까지 나오는가"를 **선형 모델(능형 회귀)** 로 계산합니다. 모델은 전문가 표시 사진
   **870장**(학습용)으로 맞추었습니다. 가중치는 9 kB이고 프로그램에 들어 있습니다(`cup_weights.py`) — 인터넷이나 추가
   설치가 필요 없습니다.
4. 둘레를 따라 매끄럽게 한 뒤, 그 경계를 벽으로 하는 오목한 모양을 만듭니다. 그다음은 전과 같습니다(등고선 → 노란 선).

* **혈관 꺾임**: 혈관 모양만 읽습니다(색은 쓰지 않음). 규칙으로 찾은 꺾임은 여전히 **점으로 표시**하고, 꺾임이 넉넉히
  있어 그것만으로 경계가 서는 곳에서는 그 경계를 따릅니다.
* **하이브리드** (처음 설정): 혈관 모양과 밝기를 함께 읽습니다. 바닥 모양은 밝기로 정합니다.
* 사진에 혈관도 창백한 곳도 보이지 않으면 전처럼 컵을 그리지 않습니다.

## 측정에 쓴 사진
* Chen 외, "A Fundus Image Dataset for Domain Generalization in Joint Segmentation of Optic Disc and Optic Cup" (2023),
  CC BY 4.0, <https://zenodo.org/records/8009107> — REFUGE · Drishti-GS · ORIGA의 사진을 디스크 둘레로 잘라 디스크 · 컵
  마스크를 붙인 것. (사진은 이 저장소에 넣지 않았습니다.)
* **학습용 870장**으로 모델을 맞추고 값을 정했습니다(다섯 묶음 교차 검증). **시험용 281장**은 아래 표를 내는 데 썼습니다.
  단, 모델의 종류(선형으로 충분한지)를 고르던 중 시험용 결과를 한 번 보았습니다 — 그 뒤의 조정은 학습용 사진으로만 했습니다.
* 재는 것: 프로그램이 **스스로 그린 컵**(디스크 C/D 탭의 자동 맞춤과 같은 경로)의 **수직 C/D**가 전문가의 값과 얼마나
  다른가, 그리고 컵 넓이가 얼마나 겹치는가(Dice, 1이 완전 일치).
* 다시 재기: `python tools/eval_cup.py "…/Processed_Fundus_Images" --split test [--disc auto]`,
  모델 다시 맞추기: `python tools/train_cup.py "…/Processed_Fundus_Images"`

## 결과 (시험용 281장)

컵만 평가 — 디스크는 전문가가 그린 경계:

| 방식 | 컵을 못 그린 사진 | 수직 C/D 오차 (평균) | 오차 0.1 이내 | 오차 0.2 이내 | 컵 겹침 (Dice) |
|---|---|---|---|---|---|
| 밝기 (바뀌지 않음) | 0 % | 0.122 | 45.2 % | 81.5 % | 0.64 |
| 혈관 꺾임: 전 → 후 | 85.4 % → **1.4 %** | 0.104 → 0.100 | 56.1 % → 59.6 % | 85.4 % → 85.9 % | 0.78 → **0.81** |
| 하이브리드: 전 → 후 | 0 % | 0.116 → **0.076** | 47.3 % → **69.8 %** | 82.6 % → **96.1 %** | 0.65 → **0.85** |

* 혈관 꺾임의 "전" 오차는 컵을 그린 **15 %의 사진만**의 값입니다. "후"는 거의 모든 사진(98.6 %)의 값입니다.
* 하이브리드가 컵을 작게 읽던 치우침: −0.093 → −0.022.

프로그램이 디스크 경계도 스스로 찾았을 때:

| 방식 | 수직 C/D 오차 (평균) | 오차 0.1 이내 | 오차 0.2 이내 | 컵 겹침 (Dice) |
|---|---|---|---|---|
| 하이브리드: 전 → 후 | 0.124 → **0.081** | 43.1 % → **69.4 %** | 82.6 % → **94.7 %** | 0.65 → **0.85** |
| 혈관 꺾임: 전 → 후 | 0.100 (15 %의 사진) → 0.104 (98.6 %의 사진) | 70.7 % → 58.5 % | 85.4 % → 84.8 % | 0.78 → 0.81 |

카메라 · 병원별 하이브리드(전문가의 디스크 경계): REFUGE 0.108 → 0.060, ORIGA 0.106 → 0.075, Drishti-GS 0.162 → 0.103.

참고로 전문가끼리도 사진 한 장의 수직 C/D는 0.1 ~ 0.2쯤 다릅니다(`docs/cd_ratio.md`).

## 한계
* 여전히 **사진 한 장의 추정**입니다. 열 장 중 세 장은 0.1 넘게 다릅니다 — 노란 선은 출발점이고, 점을 끌어 다듬은 것이
  측정값입니다.
* **혈관 꺾임 방식만으로는 하이브리드보다 덜 정확합니다**(오차 0.100 대 0.076). 특히 Drishti-GS 사진에서는 0.156으로
  밝기 방식과 비슷했습니다. 처음 설정은 하이브리드입니다.
* 측정에 쓴 사진은 일반 안저카메라(약 45°)로 찍은 세 곳의 사진입니다. **초광각(RetiCam 176°) 사진**은 유두가 작게 찍히고
  색이 달라 같은 정확도를 기대할 수 없으며, 표시가 달린 초광각 사진이 없어 재지 못했습니다.
* 학습용 사진의 "컵"은 그 자료의 전문가들이 사진 한 장(일부는 스테레오)에서 그린 것입니다. 병원마다 그리는 버릇이 다르고,
  모델은 그 평균을 따릅니다.
* 한 장을 읽는 데 약 0.2초가 걸립니다(전보다 약 0.05초 더).
* 두 장 스테레오의 **시차 + 혈관 꺾임**은 바꾸지 않았습니다(시차가 있을 때는 규칙으로 찾은 꺾임만 씁니다).
