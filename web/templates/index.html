소니 카메라 연결 (ZV-E10 II · FX3 · USB 스트리밍)

소니 카메라는 USB 케이블 하나로 웹캠처럼 연결됩니다(별도 캡처보드·드라이버 불필요).

  1. 카메라 설정: MENU → 설정(Setup) → USB → USB 연결 모드 → USB 스트리밍
    (또는 '연결 시 선택'으로 두고 연결할 때 'USB 스트리밍'을 고름 · FX3는 펌웨어 Ver.2.00 이상 필요)
  2. 해상도: 같은 USB 메뉴의 USB 스트리밍 출력 해상도/프레임을 4K(2160p) 또는 HD(1080p)로 설정
  3. 카메라 USB-C 단자와 PC를 연결합니다 (4K는 USB 3 케이블·포트 권장). 카메라 화면에 'USB 스트리밍'이 표시됩니다.
  4. 이 프로그램에서 카메라 시작 → 목록에 ★ 표시된 소니 카메라가 자동으로 선택됩니다. 상단에서 4K / 1080p를 고를 수 있습니다.

· 촬영 중 카메라 화면이 꺼지지 않게 자동 전원 끄기 온도: 높음(MicroREC 설정 안내와 동일)을 권장합니다.
· 카메라 자체 셔터로 고해상도 원본(2,400만 화소)을 찍는 원격 제어는 소니 Camera Remote SDK 로 데스크탑 앱에 추가 예정입니다.
